# 左營區與多行政區地圖圖層設計

## 目標與範圍

LanePilot 的路段清單與標註工作區維持一個行政區單選。當使用者選擇左營區時，地圖顯示左營區完整道路網；使用者也可勾選零個或多個行政區作為背景路網，以確認跨區道路和標註情況。未選主行政區時，不載入任何道路圖層。

最新公開 `main` 已含左營區 `area/4212533` shard（2351 個路段、1519 個路口）及六個可用行政區。本次不重複同步資料；改動範圍是地圖主區和背景區分層，以及背景行政區多選。

## 資料與載入

- 主行政區維持現有單選，決定路段清單、搜尋、編輯和標註寫入的範圍。
- 主圖層以 `/api/map-segments?district_area_id=<areaId>&map_scope=primary` 載入。它只回傳該區 shard 的路段，即使該區的詳細資料仍保留相鄰區上下文。
- 「地圖背景區」核取清單列出 `region_manifest.json` 已同步、且不是主區的行政區。每一區在勾選時才呼叫相同的 `map_scope=primary` API；取消勾選時只從地圖移除該區圖層。
- 同一工作階段快取已成功載入的背景區回應；切換主區時清除背景勾選、背景圖層與快取，避免把前一份工作脈絡誤帶到新區。
- 日後要增加可勾選區域時，以 `scripts/sync_region_shards.py` 將私有輸出 shard 加進 manifest；介面無須再列出硬編碼行政區。

## 視覺與互動

- 主圖層使用目前完整樣式：灰色代表未標註、綠色代表已標註、橘色代表高優先，且選取道路及目標道路保留既有突出顏色與粗度。
- 背景圖層使用相同的灰、綠、橘狀態語意，但採較細線條、低透明度及較低飽和度，形成灰色蒙版感。背景道路只顯示 tooltip，不開啟編輯表單，避免在主清單仍屬另一行政區時誤編背景道路。
- 背景圖層與主圖層重複的道路以 `object_identity.nav_segment_key` 去重，主圖層優先顯示。背景區之間也只保留第一條同 key 的道路。
- 道路幾何不得在行政區邊界裁切；被某一 shard 收錄的 LineString 要完整顯示。標註同樣以 `nav_segment_key` 儲存，因此跨區道路永遠只有一筆標註。

## 錯誤與效能

- Manifest 或指定 shard 缺失時，沿用 adapter 的清楚錯誤；不得顯示不完整路網。
- 不預載主區或背景區資料。保留請求序號，快速切換主區或勾選時，過期回應不得覆寫最新地圖狀態。
- 背景區只作地圖脈絡，不會混入主區路段清單、搜尋結果或任務指派。
